TOC procedural bookmark — shader reference

Rendering parity: src/shaders/tocBookmark.frag uses the same hash, noise, fbm, angularCuts, outer-mask / organic / chisel / micro stack, paint pass (fbm(p*4) thickness + u_densityVar), hover flame, and depth pass as src/vfx/chiselFrameOverlay.ts (CHISEL_FRAGMENT). The only geometric difference is the base SDF: a solid horizontal bookmark (sdBookmarkHorizontal) instead of a rectangular rim built from sdBox.

Wiring lives in src/components/TocProceduralRow.vue. u_borderWidth and u_organicAmp are recomputed on each resize using the same pixel→normalized formulas as the card overlay (borderPx = 3.1, organicPx = 5.5, clamped with the same caps).

Base hue (u_color)

Fixed to #00ffcc for the TOC strip. Inactive label colour follows --color-text via u_textColor.

Chisel density (u_chiselDensity)

In angularCuts(), coordinates scale as q = p * density before the layered fract waves. Higher density → finer shard bands along the edge; lower → broader chips.

Chisel depth (u_chiselDepth)

angularCuts() is multiplied by u_chiselDepth and innerProtect, then added to the displaced SDF (same weighting as the card shader). Higher depth → deeper notches.

Chisel chaos (u_chiselChaos)

Phase offsets inside the fract waves (identical to card angularCuts — no extra hidden time term; animation comes from noise(p * 3.0 + u_time * 0.05) in the mask only).
