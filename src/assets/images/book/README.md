# Book page images (full-bleed)

Place artwork here for left-hand / cover / end pages. Images are masked to the deckled page shape (full bleed).

| File name | Used on |
|-----------|---------|
| `cover.png` (or `.jpg`) | Cover (front of first leaf) |
| `understand.png` | Understand left page |
| `analyse.png` or `analyze.png` | Analyze left page |
| `brew.png` | Brew left page |
| `deliver.png` | Deliver left page |
| `end.png` | End page (last leaf back) |

Recommended aspect: **2:3** (e.g. 1024×1536). PNG, JPG, or WebP.

Missing keys fall back to coloured placeholders until files are added.
